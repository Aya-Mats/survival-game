# survival-game

HTML / CSS / JavaScript で作る、ブラウザで動く 2D 見下ろし型サンドボックスサバイバルゲームです。

木材・石・ベリーを集めながら、HP、満腹度、スタミナを管理し、昼夜サイクルと夜に出現する敵をしのいで生き延びます。現在は外部ライブラリやサーバーを使わない、静的ファイルだけで動く構成です。

## 現在できること

- プレイヤーをマップ上で移動する
- Shift キーでダッシュする
- 木、石、ベリーの資源を採取する
- 木材、石、ベリーをインベントリで管理する
- HP、満腹度、スタミナを確認する
- 時間経過による昼、夕方、夜のサイクルを体験する
- 夜に出現する敵から逃げる、または攻撃する
- ベリーを食べて満腹度と少量のHPを回復する
- 木材と石を使って焚き火をクラフトする
- 木材と石を使って小屋をクラフトする
- ゲームオーバー後にリスタートする
- PCキーボードとスマホ向けタッチ操作で遊ぶ

## ローカルでの起動方法

このゲームは静的ファイルのみで構成されています。基本的には `index.html` をブラウザで開くだけで起動できます。

1. リポジトリを取得する
2. `index.html` をブラウザで開く
3. ゲーム画面が表示されたら操作を開始する

ローカルサーバーは必須ではありません。今後、画像や音声などの外部アセットを追加した場合は、ブラウザの制約に合わせてローカルサーバーが必要になる可能性があります。

## PCでの操作方法

| 操作 | キー |
| --- | --- |
| 移動 | `WASD` または `矢印キー` |
| ダッシュ | `Shift` |
| 採取 | `E` |
| 攻撃 | `Space` |
| ベリーを食べる | `F` |
| 焚き火クラフト | `C` |
| 小屋クラフト | `H` |
| 一時停止 / 再開 | `P` |

## スマホでの操作方法

スマホやタッチ端末では、画面下部にタッチ操作UIが表示されます。

- 左側の仮想スティックで移動
- `採取` ボタンで近くの資源を採取
- `攻撃` ボタンで近くの敵を攻撃
- `食べる` ボタンでベリーを食べる
- `焚き火` ボタンで焚き火をクラフト
- `小屋` ボタンで小屋をクラフト
- `停止` ボタンで一時停止 / 再開

## 現在のゲームループ

現在のゲームは `main.js` の `requestAnimationFrame` で毎フレーム更新されます。

1. 入力キューを処理する
2. 一時停止中またはゲームオーバー中でなければ状態を更新する
3. 時間を進め、昼夜サイクルと日数を更新する
4. プレイヤーの移動、スタミナ、満腹度、HPを更新する
5. 焚き火など、寿命のある構造物を更新する
6. 夜であれば敵をスポーンし、昼であれば敵を減らす
7. 敵の移動、焚き火による忌避、プレイヤーへの接触ダメージを更新する
8. HPが0以下ならゲームオーバーにする
9. Canvasを再描画し、HUDを同期する

現時点の `AGENTS.md` はエージェント情報を記録するための短いファイルですが、今後ルールや作業方針が追加された場合は、その内容に従ってください。

## 開発メモ

- 新機能を追加する前に、既存のPC操作とスマホ操作が壊れていないか確認する
- 外部ライブラリを追加する場合は、目的と必要性をREADMEまたはPRで説明する
- サーバー化やGitHub Pages設定変更は、ゲーム本体の変更とは別の作業として扱う
- ゲームバランス変更は、リファクタやドキュメント整備とは分けて行う
